# Frontend — Collection Anny

Application cliente construite avec React.js et Vite.

Les pages et composants seront organisés progressivement dans `src/`.

## Pages prévues
- Accueil
- Catalogue et catégories
- Détail d'un produit
- Panier
- Connexion et inscription
- Validation et suivi de commande
- Administration (espace protégé)

Le code de l'interface sera ajouté dans la prochaine étape de mise en place technique.
