# Backend — Collection Anny

API REST prévue avec Node.js et Express.

Les responsabilités principales seront :
- authentification et autorisation ;
- gestion des produits et catégories ;
- gestion du panier et des commandes ;
- gestion des stocks ;
- validation des données et gestion des erreurs ;
- connexion sécurisée à MySQL.

Les routes, contrôleurs, modèles et middlewares seront ajoutés progressivement.
