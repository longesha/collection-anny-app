# Base de données — Collection Anny

La base de données prévue est MySQL.

Les premières entités à concevoir sont :
- utilisateurs et rôles ;
- catégories ;
- produits ;
- variantes (tailles et couleurs), si nécessaires ;
- stocks ;
- commandes et lignes de commande ;
- adresses de livraison ;
- paiements et statuts.

Le schéma relationnel sera défini et validé avant la création des migrations SQL.
